# Easy POS

A Flutter-based Point of Sale (POS) application designed to manage products, categories, clients, and sales through a simple and user-friendly interface.

## Features

- Product Management
- Category Management
- Client Management
- Sales Management
- Sales Statistics
- Local SQLite Database
- Responsive UI
- Onboarding Screen

## Tech Stack

- Flutter
- Dart
- SQLite
- GetIt
- DataTable2
- Intl
- Animate_Do

## Project Structure

```
lib
├── helpers
├── models
├── views
├── widgets
└── main.dart
```
